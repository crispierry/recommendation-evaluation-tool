What the synthetic feed evaluation found

A decision-ready analysis of same-day recurrence, five-day continuity, RFY alignment, and catalog persistence. Every result is computed from this tool’s frozen fictional dataset.

Executive Summary

Surface alignment

RFY represents only part of the visible recommendation stream.

For each routine profile, the first 30 recommendations on Synthetic Day 5 are checked against that profile’s separate 30-title synthetic RFY rail.

Controlled repetition

Exact-clip recurrence separates the three test profiles.

Each profile has three independent 20-position runs. A repeat counts only when the identical canonical clip appeared in an earlier run.

Top recurring exact clips by profile

Titles present in every controlled run

Title persistence is deliberately separate from exact-clip recurrence: different canonical clips under the same fictional title may contribute.

Five synthetic days

Adjacent-day overlap does not guarantee five-day persistence.

Synthetic Day 5’s first 50 recommendations are compared with the same profile’s first 50 on each of the four earlier days.

Titles present across all five days

A title qualifies only if it appears at least once in every daily Top-50 window. When none qualify, the table shows the nearest persistent titles so the absence is visible rather than hidden.

Decision use

Use the measures together, but never blend their grains.

The tool is most useful as a repeatable evaluation protocol: monitor exact clips for fatigue, titles for catalog continuity, and RFY alignment for cross-surface representation.

Recommended next evaluations

  1. Add position-weighted measures to distinguish top-of-feed recurrence from lower-position repeats.
  2. Advance the five-day anchor and test whether profile ordering remains stable.
  3. Introduce controlled catalog shocks and measure how quickly novelty and RFY alignment respond.
  4. Track Review Center precision against the synthetic ground truth.

Further questions

  • Do persistent titles remain persistent when the observation window expands?
  • Does high title continuity come from the same canonical clips or from different scenes?
  • How sensitive is RFY alignment to rail size and the first-N recommendation window?
